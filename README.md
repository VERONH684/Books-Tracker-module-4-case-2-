Название: Трекер прочитанных книг
Описание: Консольное приложение для учёта прочитанных книг с модульной архитектурой
Структура модулей:
- main.py — точка входа и пользовательский интерфейс
- storage.py — чтение, запись и управление данными в JSON
- stats.py — расчёт средней оценки и статистики по авторам
- models.py — класс Book
Как запустить: python main.py
- Пример работы: добавление книги(1):
 -Ввод - Автор: А.С. Пушкин
- Название: Капитанская дочка
- Оценка (1–5): 5
- Вывод - Книга успешно добавлена!
- (добавляем ещё одну книгу)
- Автор: А.С. Пушкин
- Название: Евгений Онегин
- Оценка (1–5): 4
- Книга успешно добавлена!
- Вывод всех книг(2):
- СПИСОК КНИГ:
- 1. Капитанская дочка - А.С. Пушкин (оценка: 5, дата: 2026-05-15)
- 2. Евгений Онегин - А.С. Пушкин (оценка: 4, дата: 2026-05-15)
- Вывод средней оценки(3):
- Средняя оценка всех книг: 4.5
- Вывод статистики по авторам(4):
- СТАТИСТИКА ПО АВТОРАМ:
- А.С. Пушкин: 2 книг, средняя оценка: 4.5
- Удаление книги(5):
- ввод - Введите название книги для удаления: Евгений Онегин
- вывод - Книга удалена!
- Введите 6, чтобы выйти из приложения
